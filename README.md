# Predicting Student Academic Outcomes

Machine learning project for the Machine Learning and Predictive Analytics assessment.

## Aim

To investigate whether machine learning can predict student academic outcomes (Dropout, Enrolled or Graduate) using demographic, socioeconomic and academic information.

## Models

- Logistic Regression - baseline model
- Random Forest - candidate predictive model

## Dataset

Predict Students' Dropout and Academic Success
UCI Machine Learning Repository
Dataset ID: 697

## Evaluation

Models will be compared using stratified cross-validation and classification metrics including accuracy, precision, recall, F1-score and confusion matrices.
